# "Bostorek-az" MEVN layihəsindən hər kəsə salamlar! :wave:

## Təsvir

Bu proyekt Full Stack bir web tətbiqidir. Express.js və Node.js backend tərəfində olmaqla, MongoDB verilənlər bazası kimi istifadə edilib. Frontend hissədə Vue.Js istifadə olunmuşdur.Web tətbiqin əsas məqsədi, istifadəçilərin kitab əlavə edə bildiyi, digər insanların kitablarını kəşf edib, rəy, bəyəni verə biləcəyi bir layihə yaratmaqdır.
İstifadəçilər Home, books, contact, login olduqdan sonra dashboard kimi səyfələrə giriş edə biləcəklər.

## Mühüm Xüsusiyyətlər

- Qeydiyyatdan keçmiş istifadəçilər yeni kitablar əlavə edə və üzərində dəyişiklik etmə haqqına sahibdir.
- Yalnız qeydiyyatdan keçən zamn kitablar haqqında rəy yazmaq və bəyəni atmaq mümkün olur.

## Quraşdırma və İstifadə

Proyekti öz kompüterinizə yükləmək və quraşdırmaq üçün aşağıdakı addımları izləyin:

1. Repozitorini klonlayın: `git clone https://github.com/cahangirasgerov2003/Bostorek-az.git`
2. Proyektin kök qovluğuna keçin: `cd Bostorek-az`
3. Dependencies-ləri quraşdırın: `npm install`
4. Proyektin frontend qovluğuna keçin və "npm run dev" kodunu çalışdırın
5. Proyektin backend qovluğuna keçin və "npm run start" kodunu çalışdırın
6. Brauzerdə http://localhost:port-a uyğun porta daxil olun.
